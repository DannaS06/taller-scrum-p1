# CLI-03 Eliminar cliente

## Historia de usuario

**Como** administrador  
**Quiero** eliminar un cliente  
**Para** mantener organizada la base de datos  

## Criterios de aceptación

Dado que el cliente existe  
Cuando el administrador confirma eliminar  
Entonces el sistema elimina el cliente  

Y el cliente desaparece de la lista  

Y el sistema muestra la lista actualizada
