# Prototipo en Figma

El prototipo del sistema fue diseñado en Figma.

Link: https://www.figma.com/design/bNtCSutJRYqfYnmosBMoyz/Untitled?node-id=1-21&p=f&t=y1VReARRiM19pJRe-0

## Descripción:

El prototipo incluye:

- Pantalla de inventario
- Pantalla de clientes
- Formularios de registro
- Consultas
- Edición

Este prototipo representa la interfaz visual del sistema ERP.
