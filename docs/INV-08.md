# INV-08 Historial de movimientos

## Historia de usuario

**Como** administrador  
**Quiero** ver el historial de movimientos  
**Para** auditar el inventario  

## Criterios de aceptación

**Escenario 1: Visualización correcta**

Dado que existen movimientos registrados  
Cuando accedo al historial  
Entonces el sistema muestra la lista de movimientos  

---

**Escenario 2: Sin movimientos**

Dado que no existen movimientos  
Cuando accedo al historial  
Entonces el sistema muestra una lista vacía
