# Code Review

Debido a que el repositorio fue trabajado por una sola persona, los Pull Requests fueron revisados por el mismo autor antes de realizar el merge.

Se verificó que cada historia de usuario cumpliera con:

- Documentación completa
- Convención de commits
- Creación correcta del Pull Request
- Asociación con su Issue correspondiente
- Cumplimiento de Definition of Done

Esto permitió mantener la calidad y trazabilidad del proyecto.
