# Visión del Producto

## Nombre

ERP para Asaderos de Pollo

## Descripción

Sistema ERP que permite gestionar inventario y clientes en asaderos de pollo.

## Problema

Actualmente el control se realiza manualmente, generando errores y pérdida de información.

## Objetivo

Automatizar la gestión.

## Usuarios

Administrador del asadero

## Beneficios

- Mejor control
- Menos errores
- Ahorro de tiempo
