# CLI-02 Editar cliente

## Historia de usuario

**Como** administrador  
**Quiero** editar los datos de un cliente  
**Para** mantener la información actualizada en el sistema  

## Criterios de aceptación

Dado que el cliente existe en el sistema  
Cuando el administrador edita los datos correctamente  
Entonces el sistema guarda los cambios  

Y muestra la información actualizada  

Y el cliente actualizado aparece en la lista
