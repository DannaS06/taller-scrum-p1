# Definition of Done (DoD)

La Definition of Done establece los criterios que debe cumplir una historia para considerarse terminada.

Una historia se considera Done cuando:

- El documento de la historia está creado en la carpeta docs

- Existe un Issue en GitHub asociado

- Existe una rama feature asociada

- Existe al menos un commit relacionado con la historia

- Existe un Pull Request creado y aprobado

- El Pull Request fue mergeado a la rama dev

- Los criterios de aceptación fueron verificados

- El prototipo en Figma está actualizado

- Los diagramas PlantUML están actualizados

- La historia está registrada en la matriz de trazabilidad

## Objetivo

Garantizar la calidad, trazabilidad y completitud de cada historia desarrollada.
