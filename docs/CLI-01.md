# CLI-01 Registrar cliente

## Historia de usuario

**Como** administrador  
**Quiero** registrar un cliente con nombre, documento, teléfono y correo  
**Para** tenerlo disponible en el sistema  

## Criterios de aceptación

Dado que el administrador está en el formulario  
Cuando ingresa nombre, documento, teléfono y correo válidos  
Entonces el sistema registra el cliente correctamente  

Y el cliente aparece en la lista
