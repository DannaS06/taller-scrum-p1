# CLI-04 Consultar cliente

## Historia de usuario

**Como** asistente  
**Quiero** consultar clientes  
**Para** ver su información  

## Criterios de aceptación

Dado que existen clientes registrados  
Cuando el asistente realiza una búsqueda  
Entonces el sistema muestra los clientes encontrados  

Y muestra nombre, documento, teléfono y correo  

Y permite visualizarlos correctamente
